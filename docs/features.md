# List of Features

## List of Features by Use Case

- "Play a Game" Use Case
  - Start a game
  - View the board
  - Place a stone
  - Check the outcome
- "View My Past Game Results" Use Case
- Display my game results

## About the "Place a Stone" Feature
- The following proccesses are likely to be involved interally 
- Check whether a stone can be placed at the selected position
- Place the stone
- Flip the stone
- Determine whose turns it is next
  - If a move cannot be made, it is automatically skipped
- (Once the winner is determined) End the game

## About Players
- No player registration feature will be included on your own PC and played by a single player
